# Provider icon sources

These first-party icons identify the external services supported by Pets. App
icons were copied from the exact official macOS applications detected by the
tracker on the development machine and resized to 256 px without changing their
artwork. The original Claude, Codex, and Copilot assets were collected on
2026-08-29; the remaining assets were collected on 2026-08-30.

- `claude.png`: Claude Desktop `TrayIconTemplate-Dark@3x.png`.
- `codex-dark.png`: ChatGPT `icon-codex-dark-color.png`.
- `codex-light.png`: ChatGPT `icon-codex-light.png`.
- `github-dark.png`: GitHub Copilot `tray-icon-light.png` for dark appearances.
- `github-light.png`: GitHub Copilot `tray-icon.png` for light appearances.
- `cursor.png`: Cursor `Cursor.icns`.
- `ollama.png`: Ollama `icon.icns`.
- `gemini.png`: Gemini `AppIcon.icns`.
- `antigravity.png`: Antigravity IDE `Antigravity IDE.icns`.
- `hermes.png`: Hermes `icon.icns`.
- `t3code.png`: T3 Code (Alpha) `icon.icns`.
- `open-design.png`: Open Design `icon.icns`.
- `kiro.png`: Kiro `Kiro.icns`.
- `zed.png`: Zed `Zed.icns`.
- `windsurf.png`: Windsurf `Windsurf.icns`.
- `notebooklm.png`: the installed NotebookLM Chrome app `app.icns`.
- `lm-studio.png`: LM Studio `icon.icns`.
- `stitch.png`: the installed Stitch Chrome app `app.icns`.
- `opencode.png`: OpenCode's official production desktop icon at
  `anomalyco/opencode/packages/desktop/icons/prod/icon.png`.
- `pi-light.png` and `pi-dark.png`: pi's official `https://pi.dev/logo-auto.svg`;
  rendered with the black light-appearance and white dark-appearance fills
  defined by that source file.

All provider names and marks are trademarks of their respective owners. Their
marks are used only to identify the corresponding integrations.
