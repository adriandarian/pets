# Provider icon sources

These first-party icons identify the external services supported by Pets. They
were copied from the providers' official macOS applications installed on the
development machine on 2026-08-29 and resized only where noted.

- `claude.png`: Claude Desktop `TrayIconTemplate-Dark@3x.png`.
- `codex-dark.png`: ChatGPT `icon-codex-dark-color.png`, resized to 256 px.
- `codex-light.png`: ChatGPT `icon-codex-light.png`, resized to 256 px.
- `github-dark.png`: GitHub Copilot `tray-icon-light.png` for dark appearances.
- `github-light.png`: GitHub Copilot `tray-icon.png` for light appearances.

Claude, Codex, GitHub, and GitHub Copilot are trademarks of their respective
owners. Their marks are used only to identify the corresponding integrations.
