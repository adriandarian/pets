## Automatic Updates

Pets can now install new versions directly from GitHub Releases.

### What's new

- Checks the Pets GitHub release page for newer versions.
- Downloads and installs the published `Pets-<version>.zip` automatically.
- Relaunches Pets after the update finishes.
- Preserves configured pets, positions, preferences, keys, and collection progress.

Pets remains signed with the maintainer's Apple Development certificate and hardened runtime, but it is not Developer ID signed or notarized. If macOS blocks the first launch, Control-click `Pets.app`, choose **Open**, and confirm.
