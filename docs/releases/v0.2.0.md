## The Cat Update

Whiskerkin arrives as Pets' largest family yet: fifteen distinct cats with unique silhouettes, coat patterns, personalities, and complete animation sets.

### What's new

- Fifteen Whiskerkin cats: Loaflet, Inkpaw, Marmalade, Mittens, Pebble, Calypso, Soot, Bramblekit, Tuftmere, Mallow, Velvet, Bluebell, Nova, Aurum, and Mirage.
- A full 375-frame Whiskerkin animation library covering idle, busy, waiting, excited, and sleeping states.
- Seven Common, five Rare, and three Legendary cats distributed through the existing chest collection.
- Per-pet tracking assignments for Claude Code, Codex, and GitHub Copilot sessions.
- GitHub Copilot usage now contributes to collection progress alongside Claude and Codex.
- A first-launch Cat Update gift of two Common Keys.

### Installing the update

Quit Pets, download `Pets-0.2.0.zip`, and replace the existing `Pets.app`. Your configured pets, positions, preferences, keys, and collection progress remain in place.

Pets is signed with the maintainer's Apple Development certificate and hardened runtime, but it is not Developer ID signed or notarized. If macOS blocks the first launch, Control-click `Pets.app`, choose **Open**, and confirm.
